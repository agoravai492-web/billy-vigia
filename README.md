# Billy Vigia - Segurança Motorizada
Plataforma profissional de ronda com Boxer rajado no escudo.

## 🚀 Tecnologias
- PWA instalável
- Modo escuro/claro
- Push Notifications
- Offline-first
- Supabase (SQL incluso)

## 📦 Como rodar
Apenas abra o `index.html` ou faça deploy na Vercel.

## 🔐 Acessos Demo
- cliente@demo.com
- vigilante@demo.com
- central@demo.com

## 🗄️ Banco de Dados
Execute `supabase_billy_vigia.sql` no Supabase SQL Editor.

## 🏍️ Vigilante é MOTO, não bicicleta
Correção oficial: todo ícone de vigilante é motocicleta Honda Bros/XRE.
